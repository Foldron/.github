# Sécurité

Ne signalez pas une faille de sécurité dans une issue publique.

Écrivez à **eulereixcossin@ecartdescartes.org** avec : la version de Foldron (`/version`), les mods et plugins
installés, les étapes pour reproduire et l'effet observé. Vous recevrez un accusé de réception, puis un suivi
jusqu'à la correction.

Sont concernés : le jar Foldron et son amorce (téléchargements, contrôle des empreintes), le lanceur, le shim et
les mods `foldron-compat`, `foldron-pont`, `foldron-corps`. Une faille de Minecraft, de Folia, de Paper, de Fabric
Loader ou de Fabric API se signale d'abord à leur projet.
