# Foldron

Serveur Minecraft Java hybride : le **moteur Folia** (régions multi-fils de PaperMC) et **Fabric Loader** dans
la même JVM. De vrais mods Fabric et de vrais plugins Folia sur le même serveur, livré en **un seul jar** qui
installe ses bibliothèques au premier lancement.

- Minecraft Java 26.3 · Folia 26.3 · Fabric Loader 0.20.1 · Fabric API · Java 25
- Les mods Fabric s'appliquent au moteur Folia lui-même ; les plugins voient le contenu des mods.
- Le serveur de Mojang n'est jamais redistribué : il est téléchargé chez l'utilisateur.
