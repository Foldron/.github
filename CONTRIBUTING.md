# Contribuer à Foldron

- Le code propre à Foldron est sous GNU GPL version 3 ou ultérieure ; une contribution est acceptée sous cette licence.
- Java 25, `javac` et `jar` (pas de Gradle) ; les scripts de construction sont dans `outils\`.
- Une affirmation « ça marche » s'appuie sur un journal rejouable (`recette\`) : dites ce qui est mesuré, ce qui est
  seulement lu dans le code, et ce qui est supposé.
- Un défaut connu s'écrit dans la documentation ; il ne se masque pas (pas de `catch` vide, pas de retrait silencieux).
- Ne joignez jamais le jar du serveur de Mojang, ni un monde, ni un fichier contenant des données personnelles.
- Code et commentaires en français, sobres.
